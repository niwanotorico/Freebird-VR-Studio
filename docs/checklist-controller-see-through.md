# 実機確認チェックリスト：コントローラー透け表示 ＋ 掴み球オフセット

ブランチ `controller-see-through`。どちらもローカル設定（同期しない）で、
`~/.freebird/vr_studio_settings.json` の `controller_see_through` / `grab_offset_cm` に保存される。

## 0. 準備
- [ ] `freebird_plugin/vr_studio` フォルダを `~/.freebird/plugins/vr_studio/` に上書きコピーして Blender を再起動
- [ ] VR を開始し、Freebird メニュー → Plugins → View / Grab を開く
- [ ] VIEW パネルの Overlay の右に「Controller」タイル（中の文字 Normal）がある
- [ ] GRAB パネルの上段に「X / - / + / 0」（下に Axis / -0.5 cm / +0.5 cm / Reset）がある

## 1. コントローラー透け表示（VIEW → Controller）
- [ ] タイルを押すと文字が See になり、ステータスに「Controller: See-through」と出る
      （「(controller not found)」と出たら Freebird の板が見つかっていない → 見た目は変わらないはず）
- [ ] 左右の黒い板（涙型）がうっすら（約20%）になり、奥の物が見える
- [ ] 板の上のボタンアイコン（UNDO / COLOR / GROUP など）、Scale 表示、STOP VR は今まで通り塗りで見える
- [ ] 掴み球（白い球）を板の後ろに持ってきても、球が欠けずに見える（＝板の透明部分が球を隠していない）
- [ ] 板の後ろにシーンの物体があっても、板の形に欠けたりしない
- [ ] 気になる点：奥行き判定を切っているので、板が物体にめり込んだときも板が手前に描かれる。違和感があるか
- [ ] もう一度押すと Normal に戻り、板が元の濃さ・見え方に戻る
- [ ] See のまま VR を終了 → 再開しても See のまま（設定が残る）
- [ ] 利き手切り替え（Freebird の設定で左利き ⇔ 右利き）後も、左右両方の板が同じ見え方になる
- [ ] Collabo の部屋に入っている時：相手側の見た目は何も変わらない（同期されない）

## 2. 掴み球オフセット（GRAB 上段）
初期値は 0（＝v0.4 と同じ、grip 姿勢の原点）。

- [ ] 最初は Reset タイルが選択状態（青枠）、球は今まで通りの位置
- [ ] Axis（X）を押すたびに X → Y → Z → X と切り替わる
- [ ] + / - を押すと球が 0.5 cm ずつ動き、ステータスに「X axis: x+0.5 y+0.0 z+0.0 cm」のように出る
- [ ] 軸の向きを確認してメモする（grip 姿勢の軸。どの軸が「指先方向／手のひら方向／横」か）
  - X+ の向き：＿＿＿＿　Y+ の向き：＿＿＿＿　Z+ の向き：＿＿＿＿

### 「中指で掴んでいる」位置を探す手順
1. コントローラーを普通に握り、中指の第2関節あたりを見る
2. 上でメモした軸を使い、まず「指先方向」の軸で球を前後させて、中指の真横に来る位置を探す
3. 次に「手のひら方向」の軸で、球の中心がグリップボタンの表面あたりに来るよう調整
4. 横方向（左右）の軸は基本 0 のまま。ずれて見える時だけ調整
5. 決まったらステータスの値をメモ：x＿＿ y＿＿ z＿＿ cm
6. その位置で次の操作を確認する
   - [ ] 物体を握る（squeeze）と、球が触れている物が掴める
   - [ ] 球が赤くなる（掴める合図）タイミングが、見た目と合っている
   - [ ] Edit Mode で頂点が球の位置で掴める
   - [ ] 比例編集 ON で、比例編集の円が球の位置に出る
   - [ ] 右スティック上下で球の大きさを変えても、中心はオフセット位置のまま
   - [ ] 掴んで移動・回転したとき、手首をひねっても球が手と一緒に回る（ずれない）
7. ズームしてワールドの縮尺を変えても、手に対する球の位置が変わらない（オフセットはワールド縮尺に追従）
8. Reset を押すと球が元の位置に戻る

## 3. 異常時
- 何か変になったら VIEW → Controller を Normal、GRAB → Reset で元の挙動に戻る
- 値は `~/.freebird/vr_studio_settings.json` を直接編集しても変えられる（Blender 再起動で反映）
- ログ：`~/.freebird/vr_studio_debug.log`（オフセット変更が `grab offset -> (...)` で記録される）
